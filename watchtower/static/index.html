Reviewing this project? Get the review key

The shared review key is watchtower-judge-demo. It runs the full loop: arm an anomaly, watch the four agents, then approve or dismiss.

It is separate from this deployment’s operator key. Starting an investigation is rate limited and capped daily so a public key cannot run up model cost; recording a decision never is. It reaches four endpoints, can neither read nor delete anything, and no execution tool exists anywhere in the system.
